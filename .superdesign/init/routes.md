# Routes

The Cloudflare Worker serves static assets from `public/`; `src/worker.js` handles only `/api/contact`.

- `/` — `public/index.html`, primary portfolio page with navigation, hero, featured products, and contact form.
- `/about/` — `public/about/index.html`, profile and project summary.
- `/blogs/` — `public/blogs/index.html`, planned writing index.
- `/life/` — `public/life/index.html`, personal interests page.
